# Angel Wings — Telegram Mini App

Мини-приложение разворачивается на `https://app.angel-wings.ru/`. Оно открывает каталог сразу после входа через Telegram. Доступны каталог, карточка товара, корзина, профиль, история заказов (`/orders`) и страницы результата оплаты. Основной сайт продолжает работать на `https://angel-wings.ru/`.

Страницы и CSS скопированы из `vue-app` для одинакового оформления. Сессия и корзина хранятся в отдельном origin поддомена.

## Локальный запуск

```sh
cd server && npm install && npm run db:generate && npm run dev
cd telegram-mini-app && npm ci && npm run dev
```

Vite слушает порт 5174 и проксирует `/api` и `/uploads` на локальный сервер. Для настоящего `Telegram.WebApp.initData` нужен публичный HTTPS URL, открытый из кнопки бота. При открытии обычной вкладки приложение покажет сообщение о необходимости запуска из Telegram.

## Подключение поддомена

1. Создать DNS-запись `A` для `app.angel-wings.ru` с IP текущего сервера (и `AAAA`, только если сервер обслуживает IPv6). Выпустить HTTPS-сертификат для поддомена.
2. Выполнить миграцию БД **до** запуска нового сервера: `sqlite3 /path/to/database.db < server/prisma/add-telegram-mini-app-user.sql`. Затем в `server` выполнить `npm run db:generate`. Если деплой использует `prisma db push`, он может применить то же изменение вместо SQL.
3. Установить на сервере `TELEGRAM_MINI_APP_BOT_TOKEN` для бота, который открывает Mini App. Если это тот же бот, что отправляет уведомления, можно оставить переменную пустой и использовать `TELEGRAM_BOT_TOKEN`. `JWT_SECRET` тоже должен быть задан.
4. Установить `TELEGRAM_MINI_APP_URL=https://app.angel-wings.ru`. Оставить `TOCHKA_REDIRECT_BASE_URL` для основного сайта: платежи из мини-приложения вернутся на поддомен, а платежи сайта — на основной домен.
5. Собрать мини-приложение: `cd telegram-mini-app && npm ci && npm run build`. Разместить `dist/` в отдельном web root поддомена. Пример блока nginx есть в `deploy/nginx-telegram-mini-app.conf.example`; настроить его пути и порт API под свой сервер. `/api/` и `/uploads/` должны проксироваться в существующий backend. Вложенные маршруты должны возвращать `index.html` мини-приложения.
6. В BotFather указать `https://app.angel-wings.ru/` как URL кнопки Mini App.

Telegram не сообщает email и телефон. При первом заказе пользователь вводит их в корзине; служебный адрес учётной записи не подставляется. Сохранение контактов действует только при выбранном согласии в корзине. Существующий аккаунт сайта автоматически не связывается с Telegram без подтверждения владения им.

Если банк откроет страницу результата во внешнем браузере, мини-приложение использует ранее выданную сессию только для страницы результата оплаты. При отсутствии сессии страницу нужно открыть через кнопку бота.
